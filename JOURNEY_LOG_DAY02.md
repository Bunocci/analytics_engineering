**What I Learned:**
- `for` loops with `range()` – repeat code a specific number of times
- `while` loops – repeat code while a condition is true
- `break` – exit a loop immediately
- `continue` – skip the current iteration and continue
- When to use `for` vs `while`

**Key Rules I Learned:**
- Use `for` when you know how many times (e.g., "print numbers 1-10")
- Use `while` when you don't know how many times (e.g., "keep asking until user types 'done'")
- `break` stops the entire loop
- `continue` skips only the current iteration
